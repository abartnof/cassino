# Cassino Literature Review

A thorough, fully-cited literature review of the card game Cassino/Casino, compiled as background research for a video game adaptation.

- `cassino-lit-review.md` — the main review
- `cassino-lit-review.pdf` — the same review as a PDF (rebuild with `tools/build_pdf.sh`; needs pandoc and WeasyPrint)
- `research/` — per-topic research notes with sources
